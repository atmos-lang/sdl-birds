# sdl-birds

An [Atmos][atmos] + [atmos-env-sdl][env-sdl] tutorial in 11 steps.

[atmos]:   https://github.com/atmos-lang/atmos/
[env-sdl]: https://github.com/lua-atmos/env-sdl/

# Install

```
sudo luarocks --lua-version=5.4 install atmos-lang 0.8
sudo luarocks --lua-version=5.4 install atmos-env-sdl 0.3
```

# Run

```
git checkout v0.5
atmos birds-11.atm
```
